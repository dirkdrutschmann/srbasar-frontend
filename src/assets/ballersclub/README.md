# Ballers-Club-Assets

Das Logo stammt aus der vom Auftraggeber übergebenen SVG. Die Schriftdateien werden
lokal ausgeliefert, ohne Anfragen an Google Fonts oder den Referenz-Webserver.

Design- und Schriftquelle: https://alba-gropiusstadt.de/vereinssport/weekend-league
und die dort eingebundene Datei `dist/assets/app-BixiYFto.css` (11.09.2026).

- Ginto Nord Condensed, Black Italic: Überschriften
- DM Sans, Regular und Medium: Fließtext
- DM Mono, Medium: Termine und Status

Die Dateien werden durch Vite gehasht und gebündelt. Vor einer öffentlichen
Frontend-Veröffentlichung muss die Berechtigung zur Selbsthostung insbesondere
der kommerziellen Ginto-Schrift geklärt sein; ein öffentlicher Download erteilt
keine zusätzliche Schriftlizenz.
